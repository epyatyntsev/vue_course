# Урок 8. Інтеграція з API (Axios + Pinia)

Ціль уроку — навчитися робити запити до API через Axios, обробляти відповіді та керувати станом через Pinia.

## План уроку

1) Навіщо потрібні API запити у фронтенді.
2) Встановлення Axios.
3) Створення Pinia Store для API.
4) Запит даних (GET) та показ списку.
5) Створення (POST), оновлення (PUT) і видалення (DELETE).
6) Обробка помилок і стану завантаження.
7) Практика на прикладі CRUD.

## Що дивитись у коді

- `src/stores/apiStore.js` — API store з Axios.
- `src/views/ApiCrudView.vue` — CRUD інтерфейс.
- `src/router/index.js` — маршрут `/api`.
- `src/main.js` — Pinia вже підключено.

## Міні-завдання для студентів

1) Додайте кнопку "Очистити форму".
2) Додайте пагінацію (показ 3 постів і кнопка "Ще").
3) Додайте `PATCH` для часткового оновлення.
4) Додайте обробку помилок у вигляді окремого компонента.
