# Урок 10. Практика та проєкти

Ціль уроку — закріпити знання через невеликі практичні проєкти та навчитися структурувати роботу.

## План уроку

1) Постановка задачі: що має показувати дашборд.
2) Декомпозиція на компоненти та сторінки.
3) Структура папок і розподіл відповідальності.
4) Реалізація MVP.
5) Покращення та рефакторинг.

## Проєкт уроку: Панель управління (Dashboard)

Функції MVP:

- Карточки з показниками.
- Графік або список подій.
- Фільтри по даті/статусу.
- Пошук по активностях.

Можливе розширення:

- Ролі користувачів.
- Темна тема.

## Інші ідеї для практики (додатково)

### TODO-додаток

- Додавання задач.
- Стани задач (active/done).
- Фільтри (всі/активні/виконані).
- Збереження у LocalStorage.

### Міні-блог

- Список постів (API або мок-дані).
- Детальна сторінка поста.
- Коментарі (мок).
- Пагінація.

## Демо в коді (Dashboard)

У цьому курсі ми реалізували повний приклад дашборду:

- Роут: `/#/dashboard` → `src/views/DashboardView.vue`
- Store: `src/stores/dashboardStore.js`
- Dashboard service: `src/services/api/dashboardService.js`
- Компоненти:
  - `src/components/dashboard/DashboardHeader.vue`
  - `src/components/dashboard/DashboardStats.vue`
  - `src/components/dashboard/DashboardChart.vue`
  - `src/components/dashboard/ActivityPanel.vue`

## Рекомендована структура

```
src/
  components/
  views/
  stores/
  services/
  router/
```

## Мінімальні вимоги до проєкту

- 2–3 сторінки (router).
- 1 store (Pinia).
- 1 запит до API або мок-дані.
- 1 форма + валідація.
- Базова стилізація.

## Міні-завдання для студентів

1) Виберіть один проєкт та опишіть його функції.
2) Намалюйте структуру компонентів (можна схематично).
3) Реалізуйте MVP за 1–2 заняття.
